Що це таке

Graph to Music — це застосунок, що перетворює математичні функції на музику. Предмет дослідження — математика: як форма, амплітуда, частота і характер функції визначають звукову структуру мелодії.

Синус звучить плавно. Кубічна функція — з наростанням. FM-модуляція — як електронний синтезатор. Кожна функція має свій унікальний музичний «портрет».

Математична основа

Центральна ідея проєкту — дискретне перетворення функції у часовий ряд. Кожне значення f(xᵢ) інтерпретується як висота ноти nᵢ за формулою:

nᵢ = round( (f(xᵢ) − f_min) / (f_max − f_min) · 87 ) + 21

де 21 — мінімальна нота MIDI (A0), 87 — діапазон фортепіано.

Для зворотного модуля використовується дискретне перетворення Фур'є (DFT) для виділення домінантних гармонік сигналу та апроксимація методом найменших квадратів.

Ряд Фур'є (апроксимація)
f(x) ≈ Σ aₖ·cos(2πkx + φₖ)
Перша похідна (чисельна)
f′(xᵢ) ≈ (f(xᵢ₊₁) − f(xᵢ)) / (xᵢ₊₁ − xᵢ)
RMSE апроксимації
RMSE = √( Σ(f(xᵢ) − f̂(xᵢ))² / n )
